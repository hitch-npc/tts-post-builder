# Конструктор постов TTS

Собирает картинки для анонсов в Telegram-канале Ticket to Show по дизайн-системе TTS R14 и выгружает их в PNG или JPEG.
Цвета, шрифты и правила — из [TTS Design System](https://github.com/hitch-npc/tts-design-system) (`tokens.json`, `CLAUDE.md`).
Работает в браузере, без сервера и сборки: всё нужное лежит в этой папке.

## Что умеет

- **Четыре шаблона.** «Картинка в поле» — основной пост в один слайд. «Картинка полосой» — картинка во всю ширину сверху.
  «Альбом · обложка» и «Альбом · детали» — пара слайдов для поста из двух картинок.
- **Три формата:** 4:5 (1080 × 1350, пост), 1:1 (1080 × 1080), 9:16 (1080 × 1920, сторис — с полями под интерфейс сторис).
- **Светлая и тёмная тема** — цвета из `tokens.json` ядра R14.
- **Блобы по жанру:** синий, тёплый + синий, зелёный + синий. Сила — «Нет», «Тихо», «Ярко».
  «Тихо» (по умолчанию): на слайдах с картинкой один блоб в углу под текстом, на слайде деталей — оба, приглушённо.
- **Своя картинка:** загрузка с устройства, фокус по горизонтали и вертикали, масштаб, высота картинки на холсте.
- **Поля держатся всегда.** Текст важнее картинки: картинка уступает ему место, но остаётся не меньше 30 % высоты холста.
  Если места всё равно мало, название уменьшается — не больше чем на 20 % и не мельче 72 px. Если и этого не хватает,
  над предпросмотром появляется предупреждение, холст обводится красным, а выгрузка выключена, пока текст не сократят.
  Длина полей ограничена: надзаголовок — 40 знаков, название — 60, подводка — 220, абзац деталей — 360.
- **Тексты:** надзаголовок, название (размер, капс по решению владельца), подводка, строка данных — нет, 2 или 3 колонки,
  таблица деталей до 5 строк, возраст, палочки слайдов.
- **Экспорт:** PNG или JPEG (качество настраивается), размер 1× (1080 px) или 2× (2160 px).
  Кнопка «Альбом» выгружает обложку и детали за один раз. На телефоне файлы отдаются через меню «Поделиться» —
  там есть «Сохранить изображение».
- **Текст поста для Telegram** собирается из полей по шаблону канала и копируется одной кнопкой; виден счётчик
  до лимита подписи к фото (1024 знака).
- Настройки и последняя картинка сохраняются в браузере. «Сбросить» возвращает пример.

## Правила, которые держит конструктор

- Название события — Cormorant 500 обычным регистром. Капс включается вручную и только по решению владельца.
- Надзаголовок — серый капс (правило 14.3: кобальт в тексте только крупно).
- Кобальт `#0047FF` — только у активной палочки слайдов.
- Сетка 6 колонок, поля 72 px, промежуток 24 px; радиусы не больше 2 px.
- Логотип — настоящий SVG из `tts-logo.svg`, не текст.

## Как открыть по ссылке

Сайт публикуется через GitHub Pages из ветки `main`:
**Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)` → Save**.

Адрес — https://hitch-npc.github.io/tts-post-builder/. Он начинает открываться через минуту-две после включения
и обновляется после каждого push в `main`. Страница помечена `noindex`, поисковики её не показывают.

Репозиторий публичный: код, картинка примера и тексты видны всем. Личные данные сюда не кладутся —
ни реальные почты и телефоны, ни пути вида `/Users/…`.

## Запуск на своём компьютере

Открывать нужно через локальный сервер, а не двойным щелчком по файлу: иначе браузер не даст встроить шрифты в картинку.

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Файлы

| Файл | Что это |
|------|---------|
| `index.html` | Интерфейс |
| `styles.css` | Стили интерфейса и холста поста (токены R14) |
| `app.js` | Шаблоны, предпросмотр, экспорт, текст поста |
| `logo.js` | Логотип TTS из `tts-logo.svg` |
| `fonts.css`, `fonts/` | Cormorant Garamond и Manrope, кириллица и латиница — локально, чтобы попадали в экспорт |
| `vendor/html-to-image.js` | Библиотека, которая превращает холст в PNG/JPEG (MIT) |
| `assets/example.jpg` | Картинка примера |
